# 后续个人电脑和服务器部署信息表

填写“未知”优于猜测。不要提供密码或私钥；远程操作时另行授权使用安全登录方式。

## 个人电脑

| 信息 | 甲方当前已知 | 需要补充 |
|---|---|---|
| 操作系统/版本/位数 | Windows | Windows10/11、build、64位 |
| GPU型号 | 约RTX3060 | 桌面版/笔记本版、实际型号 |
| GPU显存 | 未知 | 6/8/12GB或其他 |
| NVIDIA驱动 | 未知 | nvidia-smi输出、是否允许更新 |
| CPU/内存 | 未知 | CPU型号、核心数、RAM |
| 磁盘 | 未知 | 安装路径、SSD/机械盘、可用空间 |
| 联网 | 可以 | 能否访问Python/PyPI、是否需代理 |
| 安装权限 | 未知 | 当前用户可写目录、VC++/驱动安装权限 |
| Python | 未知 | 是否已有3.11 x64；不要求必须预装 |
| 用途 | 先本机查看效果 | 仅本机/局域网共享、预计同时操作人数 |

包内双击 `04_collect_info.cmd` 获取OS、GPU/驱动、CPU、RAM、磁盘；安装检查获取实际CUDA会话和样例报告证据。回传两个outputs中的信息文件即可，无需回传业务图片。

## Linux服务器

| 信息 | 填写 |
|---|---|
| Linux发行版及版本、CPU架构 | 例如Ubuntu22.04/24.04 x86_64 |
| CPU型号/核数、内存 | 建议先按8核/32GB作为小团队部署预配置，仍需实测 |
| GPU型号、数量、每卡显存 | 单实例当前使用一张GPU |
| NVIDIA驱动及其他GPU业务 | nvidia-smi；是否共享GPU |
| Docker/Compose版本 | docker version、docker compose version |
| NVIDIA Container Toolkit | 是否安装及GPU容器测试结果 |
| 存储路径和权限 | 模型只读，data/outputs/logs可写；可用磁盘及增长预算 |
| 网络 | 内网IP、用户访问网段、8000端口可达性 |
| 联网/隔离 | 构建机能否联网、目标是否必须断网安装 |
| 运维用户 | 普通用户UID/GID、是否属于docker组 |
| 使用规模 | 浏览人数、单图同时提交人数、批次大小/频率、可接受等待时间 |
| 目标时间 | 何时安排部署和验收 |

执行 `bash deployment/linux/collect-environment.sh`，将输出保存为环境记录。Windows Server可先用Windows原生路径试运行；作为共享服务的优先交付路线为Linux Docker。

## 所有环境共同需要

- 扫描/显微图像来源、染色、倍率/MPP、样例尺寸；当前只支持普通JPG/PNG/TIF，WSI后置。
- 模型版本/哈希、类别表、阈值、许可证确认责任人。
- 最终软件ZIP/镜像摘要、SHA-256、数据保留期限和备份责任。
- 验收负责人；确认功能项、GPU、报告、批处理和性能证据，不将开发机速度直接作为目标机结果。
