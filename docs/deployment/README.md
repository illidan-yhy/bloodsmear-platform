# 部署材料索引

1. `01-Windows-RTX3060试用部署手册.md`：甲方当前电脑联网试用。
2. `02-后续部署环境信息采集表.md`：个人电脑和服务器信息交接。
3. `03-Linux服务器与离线部署手册.md`：后续联网构建、离线导入、验收记录。
4. `04-并发能力与容量说明.md`：当前代码限制、保守试用人数和压测方法。

Windows试用包提供安装、启动、状态、停止和环境采集脚本；Linux源文件包提供构建配置和操作脚本。两个包都包含模型、中文字体、官方样例；没有业务样片、旧任务、日志、开发虚拟环境或IDE配置。

Windows联网包首次安装需要联网和已安装的Python3.11 x64。后续服务运行无需联网。Linux镜像tar需要服务器构建通过后单独交付，当前不随此源文件包提供。
