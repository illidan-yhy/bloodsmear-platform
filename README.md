# 外周血涂片图像分析平台

上传外周血涂片的显微图片，查看细胞识别结果、数量和比例，并下载 Excel、PDF 报告。

> **下载说明：** 这个公开仓库提供源码，不包含模型权重或 Windows 部署压缩包。模型授权仍待确认。运行或制作部署包前，需另行取得匹配的模型，并将其放到 `models/blood-cell-yolo11/1.0.0/model.onnx`；请勿使用任意模型文件替代。甲方如需直接试用，请使用另行提供的完整部署包。

本项目把已有的细胞识别模型接入一个可在本地运行的平台，方便通过浏览器处理图片。

> 仅供科研和内部分析，不用于临床诊断。模型识别结果需要结合原图，由专业人员复核。

## 支持哪些功能

- **单张图片分析**：上传图片，查看细胞框选、分类、数量和比例。
- **批量分析**：一次提交多张图片，查看处理进度，下载整批结果。
- **报告下载**：提供 Excel、PDF、标注图片，以及便于其他软件读取的 JSON、CSV 数据。
- **本地运行**：在自己的电脑或服务器上运行，安装所需依赖后，日常分析不需要连接外部识别服务。

当前模型识别七类目标：中性粒细胞、淋巴细胞、单核细胞、嗜酸性粒细胞、嗜碱性粒细胞、红细胞和血小板。

### 批量处理有两种方式

- **独立样本（Independent）**：每张图片分别分析，适合一批图片来自不同样本的情况。
- **同一样本（Grouped）**：多张图片属于同一个样本，需要填写样本编号；系统合计数量后重新计算比例。请不要把不同样本的图片放在这一模式下汇总。

批量结果包含整批 Excel、PDF 和每张成功处理图片的独立 Excel、PDF，可一次下载为 ZIP 压缩包。PDF 以文字和表格为主，不包含图片；标注图片单独提供。

ZIP 内每张成功图片的结果放在“序号_原文件名”目录中，例如 `items/001_血涂片 样本1.png/`，方便按上传顺序找到对应图片。同名图片用序号区分，特殊字符会替换，过长名称会截短；原文件名仍完整保留在结果索引中。已有 ZIP 不自动改名。

### 如何理解比例和提示

“全部细胞比例”是各类目标占全部检测目标的比例。“白细胞分类比例”只在五类白细胞之间计算，不包含红细胞和血小板。

界面中的 **WBC** 表示白细胞总数，不是单核细胞的专属名称。没有检出白细胞时，白细胞比例显示“—”，表示无法计算，不代表比例为零。

**QC** 是质量检查提示。出现 `warning` 时，请查看具体原因并复核原图；它不是疾病诊断结论。

## 怎样开始使用

### 使用 Windows 部署包

如果已经取得单独提供的 Windows 部署包：

1. 完整解压部署包，按手册准备 Python 3.11 和显卡驱动。
2. 首次使用双击 `01_install.cmd`，完成安装和环境检查。
3. 双击 `02_start.cmd`，保持启动窗口打开。
4. 在浏览器打开 <http://127.0.0.1:8000>，上传图片并查看结果。
5. 使用结束后，在启动窗口按 `Ctrl+C` 停止服务。

这组步骤适用于打包后的部署文件，不能直接套用到刚下载的源码目录。首次安装需要联网；GPU 加速是否可用，应以目标电脑上的检查结果为准。

如需 Windows 部署手册，请使用另行提供的部署包及配套说明。

### 从源码运行（开发者）

在项目根目录打开 PowerShell，先准备 Python 3.11、uv 和兼容的 NVIDIA 驱动，再执行以下命令。首次安装可能下载较大的显卡运行依赖。

```powershell
uv venv --python 3.11 .venv
uv pip install --python .\.venv\Scripts\python.exe -r requirements-dev.lock
uv pip install --python .\.venv\Scripts\python.exe --no-deps -e .
.\.venv\Scripts\python.exe -m bloodsmear.cli serve
```

启动后在浏览器打开 <http://127.0.0.1:8000>。这里是浏览器访问地址，不要使用启动窗口中显示的 `0.0.0.0`。服务端口默认是 8000。

如需把平台接入其他软件，启动后可在 <http://127.0.0.1:8000/docs> 查看接口说明。



## 输入要求与使用限制

- 输入是数字图片，不是实物玻片。支持 JPG、JPEG、PNG、TIF、TIFF 格式的普通显微图片。
- 暂不支持 16 位灰度图像（包括 TIFF），会明确提示失败，不生成正常计数或单图报告；请提供经确认的 8 位显微图像。16 位彩色 TIFF 沿用现有读取流程，最终转换为 8 位 RGB，不代表已验证其识别准确率。
- 暂不支持 SVS、NDPI、MRXS 等整张玻片扫描文件；普通 TIFF 图片支持不等于支持 TIFF 整张玻片扫描。
- 图片应清晰，染色、倍率和采集设备差异可能影响识别效果。
- 默认每批最多 100 张，每张不超过 25 MiB，整批不超过 500 MiB。
- 当前没有用户登录和权限管理，适合本机或可信内网使用，不建议直接开放到公网。
- 平台提供识别结果，不替代人工复核；示例图片只能用于检查软件流程，不能用来证明模型准确率。

### 文件保存位置

单图结果保存在 `outputs/`，批量任务和结果保存在 `data/`，运行日志保存在 `logs/`。

批量上传的原图默认保留 24 小时，已结束任务的结果默认保留 7 天；单图结果目前不会按同样规则自动清理。日志每天分卷，默认保留 14 天。重要结果请及时下载备份。

这些运行数据、虚拟环境、IDE 配置和内部开发计划不纳入源码提交。
